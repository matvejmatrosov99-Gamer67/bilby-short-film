# Bilby — короткометражный мультфильм

Полный адаптивный фан-сайт на русском языке о короткометражке **Bilby** (DreamWorks Animation, 2018).

## Публикация
GitHub Actions автоматически восстанавливает ZIP-архив сайта, распаковывает `index.html` и папку `assets/`, а затем публикует их через GitHub Pages.

Адрес сайта:
https://matvejmatrosov99-Gamer67.github.io/bilby-short-film/

Публикация запускается автоматически после изменений в ветке `main`. Это фан-сайт; права на фильм, персонажей и кадры принадлежат правообладателям.
